# Contributing Guidelines

1. **Keep it non-destructive:** Never add MBR/disk writes, file deletion, persistence abuse, or forced crash/reboot routines.
2. **Preserve the kill-switch:** Never weaken or remove the immediate abort hotkey (`Ctrl + Alt + Q`) or safety warnings.
3. **Write clear English documentation:** Keep READMEs, docs, and code comments clear, accurate, and transparent about safety boundaries.
4. **Attribute original work:** Keep credit to the original MEMZ creator (**Leurak**) and the **danooct1** *User Made Malware* origin intact.
